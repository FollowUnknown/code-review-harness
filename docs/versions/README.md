```
v1.3.9 (已完成) ─── AST 增强 + 知识库 UI + LLM 检测

    │ ✅ 50 条 qiqiao-saas 规则 + bad_code/good_code 字段

    │ 知识有效性回归、自动提取增强、跨技术栈管理

    │ 问题定位、修复引导、复审流程
    │ 解决"评审完然后呢"的问题

    │ 能力治理、插件化、多租户
```
