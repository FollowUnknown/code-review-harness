## 迭代路线图

```
v1.3.9 (已完成) ─── AST 增强 + 知识库 UI + LLM 检测
    │
    ▼
v1.4.0 (已完成) ─── 多工程集成
    │ 产品线模型 + 需求评审页 + 4 层知识库 + 依赖扫描
    │ ✅ 数据模型 + API + 前端页面 + Q14 数据隔离
    ▼
v1.4.1 (已完成) ─── Bugfix & UX 补全
    │ 页面崩溃修复 + 字段映射 + 操作指南 + 路径校验
    ▼
v1.4.2 (已完成) ─── 版本/Contract 关系治理
    │ ✅ Contract 规范化 + 状态统一 + 清理 + 规则沉淀
    ▼
v1.4.3 (已完成) ─── Java 评审经验知识导入
    │ ✅ 50 条 qiqiao-saas 规则 + bad_code/good_code 字段
    ▼
v1.4.4 (已完成) ─── 评审执行体验优化
    │ 逐步报告：每批结果实时推送，不等全部结束
    │ 暂停/重启：保存检查点，断点续评
    │ ✅ 中断恢复 + 即时暂停反馈 + 增量检查点
    ▼
v1.4.5 (GitLab API Preview)
    │ 需求评审 Preview 改用 GitLab Compare API
    │ repo_mappings 加 GitLab 配置，Preview 秒级返回
    │ 解决"Preview 3 分钟+才能看到文件列表"的问题
    ▼
v1.5.0 (评审质量度量)
    │ 误报追踪、动态评审策略、Prompt A/B 测试
    │ GitNexus：零 Token 实时代码地图，调用链/影响分析
    │ 解决"评审准不准"的问题
    ▼
v1.6.0 (知识库深度优化)
    │ 知识有效性回归、自动提取、向量化语义搜索
    │ Graphify：跨模态知识图谱，~71.5x Token 节省
    │ 解决"知识库有没有用"的问题
    ▼
v1.7.0 (开发者评审闭环)
    │ 问题定位、修复引导、复审流程
    │ OpenCode Server：本地 Agent 常驻服务、异步评审
    │ 解决"评审完然后呢"的问题
    ▼
v2.0.0 (平台化)
    │ 能力治理、插件化、多租户
```
