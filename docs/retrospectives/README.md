# Retrospectives

阶段性开发回顾，记录每个里程碑的开发过程与 Harness 框架迭代。

## 使用方式

在达到一个阶段里程碑时，运行以下提示词生成本次回顾：

```
请根据该分支的第一个 commit 到现在，总结开发过程，并总结 Harness 迭代过程，生成回顾文档。
```

## 命名规范

文件名使用日期：`YYYY-MM-DD.md`
